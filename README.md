# PetLuma Pet ID

A mobile-first Next.js app for creating premium digital PetLuma ID cards.

## Local Setup

```bash
npm install
npm run dev
```

This MVP runs fully in the browser. It does not use a database, login, external storage, or environment variables.

## Routes

- `/`: PetLuma landing page.
- `/create`: pet profile form, local card generation, PNG download, and share button.

## Vercel

1. Push the project to GitHub.
2. Import it in Vercel.
3. Deploy.
